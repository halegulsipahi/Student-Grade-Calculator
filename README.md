# 📝 Average Calculator (C# Windows Forms)
A clean desktop application built with C# Windows Forms to calculate grade averages with real-time feedback.

## 🚀 Features
- **Input Validation:** Only numbers are allowed (0-100 range).
- **Visual Feedback:** Color-coded status badges (Green = Passed, Yellow = Conditional Pass, Red = Failed).
- **Smooth Navigation:** Enter key transitions between inputs and triggers calculation.
